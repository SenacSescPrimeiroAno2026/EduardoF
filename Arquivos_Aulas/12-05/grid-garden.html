Grid Garden

  • O que é?
    O Grid Garden é um jogo educativo que ensina CSS Grid, um sistema usado para organizar elementos em páginas web, o jogador usa códigos CSS para regar cenouras e organizar plantas no jardim.

  • Opinião
    Eu acho que é diferente, um jogo de cenouras bem legal que faz você desenvolver bem os códigos do CSS.
