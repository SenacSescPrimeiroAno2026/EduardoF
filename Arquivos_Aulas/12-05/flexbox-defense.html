Flexbox Defense

  • O que é?
    O Flexbox Defense é um jogo educativo que ensina Flexbox no CSS usando um estilo de jogo de defesa. Nele, o jogador posiciona torres usando códigos CSS para impedir a passagem dos inimigos

  • Opinião
    Eu acho que é um jogo muito bom e tem um estilo bem legal para aprender códigos de CSS.
