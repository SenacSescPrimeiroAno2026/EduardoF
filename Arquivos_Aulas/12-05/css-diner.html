CSS Diner

  • O que é?

    CSS Diner é um jogo do Google, que faz você utilizar códigos do css em objetos. E esses códigos variam entre plate, .small, #fancy, plate apple entre outros

  • Opinião

    O CSS Diner é muito útil para quem está começando a aprender CSS, porque ensina de uma forma divertida e prática. Ele ajuda a memorizar os seletores mais rápido e facilita o entendimento do conteúdo sem ficar apenas na teoria. Além disso, os desafios deixam o aprendizado mais interessante e menos cansativo.
