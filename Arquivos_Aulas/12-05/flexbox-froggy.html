Flexbox Froggy

  • O que é?
    O Flexbox Froggy é um jogo que ensina Flexbox no CSS de forma prática e divertida. Nele, o jogador usa comandos CSS para mover sapos até as folhas corretas, aprendendo alinhamento e organização de elementos na página.

  • Opinião
    Para um jogo de navegador é muito bom e faz as pessoas que estão iniciando no CSS melhorarem cada vez mais.
